Detailed Description

Transaction manager dedicated to operations performed asynchronously.

This manager prepares commands using a control SAM, and the result is available as a string to be imported and processed by a AsyncTransactionExecutorManager.

An instance of this interface can be obtained via the method keypop::calypso::crypto::legacysam::LegacySamApiFactory ::createAsyncTransactionCreatorManager(const std::string&, SecuritySetting).
